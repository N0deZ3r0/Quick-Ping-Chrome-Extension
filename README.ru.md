## Что это

Простое расширение для быстрой проверки скорости отклика любого сайта. Ввели
адрес — получили пинг в миллисекундах. Без регистрации, без настройки, без
телеметрии.

| | |
|---|---|
| **Устойчиво** | Несколько замеров за проверку, результат — медиана и джиттер |
| **Просто** | Минимум кнопок, максимум пользы |
| **Наглядно** | Цветовая индикация качества, светлая и тёмная тема |
| **Честно** | Показывает измеренное число или `ERROR` — но не заглушку |
| **Внимательно** | Следит за выбранными хостами и сообщает, когда один упал |
| **Автономно** | Ни CDN, ни шрифтов, ни аналитики — всё лежит внутри расширения |

## Что именно измеряется

Это не ICMP-пинг: расширение браузера не умеет слать ICMP-пакеты. Quick Ping
отправляет `GET` и останавливает секундомер, когда пришли заголовки ответа,
после чего сбрасывает тело, не скачивая его. Получается время до первого байта —
DNS плюс TCP плюс TLS плюс раздумья сервера, то есть ровно та задержка, которая
и ощущается при открытии сайта.

### Холодный, тёплый и джиттер

Один замер сам по себе несопоставим со следующим. Первый запрос к хосту несёт на
себе DNS-запрос и TLS-рукопожатие, каждый следующий переиспользует открытое
соединение и всего этого не делает. Показывать одно число значило бы, что тот же
сайт при втором нажатии кнопки вдруг вдвое «быстрее» — без всякой видимой
причины.

Поэтому проверка отправляет несколько запросов и разделяет их:

| | |
|---|---|
| **холодный** | первый замер, вместе с рукопожатием |
| **тёплый** | медиана остальных, по переиспользованному соединению |
| **джиттер** | разброс среди тёплых замеров |

Крупное число — тёплая медиана, если она есть, и холодный замер, если вы
запросили одну выборку. Большой разрыв между холодным и тёплым указывает на
установку соединения: DNS, TLS, расстояние. Высокий джиттер — на нестабильный
канал.

### Что ещё стоит знать

- Любой ответ считается ответом. `403` или `500` тоже доказывают, что запрос
  дошёл и вернулся, поэтому показываются как обычный результат, помеченный кодом.
- Хосту, который принял соединение и молчит, даётся 5 секунд, после чего
  проверка прерывается. Таймаут и обрыв соединения записываются раздельно — что
  именно случилось, видно во всплывающей подсказке строки истории.
- Работают `http://`, порты, пути и IP-адреса: `localhost:3000/health` и
  `192.168.1.1` — корректный ввод.

## Наблюдение за хостом

Вкладка **Наблюдение** держит список адресов, которые проверяются в фоне
примерно с выбранной периодичностью — независимо от того, открыт ли попап.
Уведомление приходит **только когда хост меняет состояние**: перестал отвечать и
потом снова ответил. Инструмент, дёргающий на каждую проверку, — это инструмент,
который отключают в первый же час.

Расписание держится на `chrome.alarms`, поэтому интервал приблизительный, а одна
минута — тот минимум, который Chrome гарантирует. Фоновая проверка делает одну
выборку: там важно, жив ли хост, а не насколько он быстр.

## Установка

Расширения нет в Chrome Web Store — ставится распакованным.

1. **Скачайте файлы.** Откройте [Releases](https://github.com/N0deZ3r0/Quick-Ping-Chrome-Extension/releases/latest),
   скачайте архив и распакуйте в любую папку.
2. **Откройте страницу расширений.** Перейдите на `chrome://extensions/` и
   включите **режим разработчика** в правом верхнем углу.
3. **Загрузите.** Нажмите **Загрузить распакованное расширение** и выберите
   распакованную папку.
4. **Закрепите.** Нажмите на «булавку» 📌 рядом с Quick Ping, чтобы значок
   остался в панели.

Готово — в Chrome появился значок ⚡.

### Chrome ругается на расширение

Это нормально для любого распакованного расширения. Нажмите **Подробнее** под
предупреждением, затем **Всё равно установить**. Дальше расширение работает как
обычно.

### Какие файлы нужны

```text
manifest.json    обязательно
popup.html       обязательно
popup.css        обязательно
popup.js         обязательно
background.js    фоновое наблюдение
lib/             общие модули
icons/           папка с иконками
_locales/        переводы интерфейса (английский, русский)
```

Всё остальное в репозитории — `tests/`, `package.json`, `.github/` — это
обвязка. У расширения нет ни сборки, ни зависимостей.

## Обновление своей сборки

1. Замените файлы в папке.
2. Нажмите **Обновить** на карточке расширения в `chrome://extensions/`.
3. Изменения применятся сразу.

## Разрешения

| Разрешение | Зачем оно нужно |
|---|---|
| `storage` | Хранить историю, закреплённые адреса и список наблюдения локально |
| `http://*/*`, `https://*/*` | Отправить тот самый запрос, время которого и есть измерение, и прочитать код ответа |
| `activeTab` | Прочитать адрес текущей вкладки, когда вы нажали **Эта вкладка** |
| `alarms` | Будить расширение для фоновых проверок |
| `notifications` | Сообщать, что наблюдаемый хост упал или снова отвечает |

Именно доступ к хостам делает возможным честное измерение: без него браузер
прячет ответ за CORS, и расширению остаётся гадать по неудачной загрузке
картинки. Используется для адреса, который вы ввели, для адреса вкладки, о
которой вы явно спросили, и для хостов из списка наблюдения — и запросы не несут
ни кук, ни реферера.

`activeTab` ничего не даёт до нажатия кнопки: Chrome выдаёт адрес текущей вкладки
в этот момент и забирает обратно после. `alarms` и `notifications` существуют
только ради списка наблюдения — при пустом списке будильник снимается и в фоне
не работает ничего.

Больше никуда ничего не отправляется. История лежит в браузере и его не
покидает, аналитики нет, а попап не грузит ни удалённых шрифтов, ни стилей, ни
скриптов — все ресурсы лежат внутри расширения.

## Горячая клавиша

**Alt+Shift+P** открывает попап. Изменить или снять её можно на странице
`chrome://extensions/shortcuts`; если комбинация уже занята, Chrome молча
проигнорирует предложенную.
